🌍 WanderSky - Modern Travel Website

WanderSky is a modern, responsive, and colorful travel agency homepage built from scratch using pure HTML5 and CSS3.

🚀 Live Demo
Click here to view the live website: [ https://sindhuja-tech.github.io/Trip-advisor-clone/]

🌟 Key Features
- Modern Navigation: Responsive navbar with logo and smooth scroll menu.
- Hero Search Section: Custom search input with budget and rating filters.
- Card-based Listings: Modern card layouts for Destinations, Hotels, and Restaurants.
- Responsive Design: Optimized for mobile, tablet, and desktop using CSS Media Queries.
- Pure Local Assets: Custom styled with local image assets for fast loading.

## 🛠️ Tech Stack
HTML5:Semantic structure
CSS3: Flexbox, Custom Color Palette, Transitions & Media Queries
